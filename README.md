## 🚀 About Me

I'm a **Full-Stack Engineer** with **2+ years shipping production apps** for international clients across Switzerland, Dubai, and the US. I own the full cycle — architecture, mobile + web frontends, backends, payments, and deployment.

Most recently I built the complete **Flutter + React 19/TypeScript frontend and FastAPI backend** for [**Handman**](https://handman.ch) — a live Swiss craftsmen marketplace with 100+ screens, 4 user roles, real-time chat, biometric/passkey login, a 4-language UI (DE/FR/IT/EN), and Stripe/TWINT/PostFinance payments, deployed with Docker on Coolify.
